# 婴儿期 Demo 策划（v0.1）

## 1. 一句话概念
用婴儿的眼睛重新看世界：视角低、手笨、看不清，但一切都新奇。玩家在一个温馨的家里度过“婴儿的一天”，通过抓、爬、哭、笑与世界和家人互动，最终学会**站起来迈出第一步**——Demo 结束，接入下一阶段。

## 2. Demo 目标
- 时长：10–15 分钟可通关
- 验证三件事：
  1. 第一视角“婴儿身体”的手感是否有趣（低视角、笨拙的手、模糊视野）
  2. 需求系统 + 交互是否能驱动玩家行动
  3. “成长”的感觉：能力随进度解锁（翻身 → 爬 → 扶站 → 走）

## 3. 核心玩法

### 3.1 婴儿身体与操作
| 能力 | 操作（PC） | 说明 |
|---|---|---|
| 环视 | 鼠标 | 初期转头范围受限，随成长放开 |
| 抓取 / 松手 | 左键 / 右键 | 双手各自独立（左手 Q、右手 E 切换） |
| 塞嘴里 | F | 婴儿天性；能吃的加饱腹，不能吃的触发家长反应 |
| 爬行 | WASD | 解锁后可用，速度慢、有摇晃感 |
| 哭 | 按住空格 | 呼叫家长，家长 AI 会来查看需求 |
| 笑 / 咿呀 | R | 回应家长，提升“亲密”值 |
| 扶站 / 走 | 靠近家具按 Shift | Demo 结局技能 |

移动端（后续）：左摇杆爬行，右侧滑动环视，按钮抓/哭/笑。

### 3.2 需求系统（HUD 左上 4 个泡泡）
- 🍼 **饱腹**：随时间下降，喂奶 / 喂饭恢复
- 🌙 **困意**：低时视野变暗变模糊，可在婴儿床、怀里睡觉恢复
- ❤️ **亲密**：被抱、对家长笑、玩玩偶恢复
- ✨ **好奇**：探索新物件、看新东西获得，满了解锁新能力

需求过低 → 哭闹自动触发，家长前来处理（不会失败，只是节奏变慢）。

### 3.3 成长里程碑（主线）
1. **醒来**：婴儿床里，只能转头、伸手够床铃（教学：抓取）
2. **喂奶**：哭 → 妈妈抱起 → 喂奶（教学：哭 / 需求）
3. **翻身与爬行**：在客厅地毯上被放下，追滚动的球，解锁爬行
4. **探索客厅**：积木、狗狗、遥控器、抽屉……每件新物件 +好奇
5. **喂饭**：高脚椅上抓勺子、打翻碗（物理趣味）
6. **扶站 & 第一步**：扶沙发站起，在家人的鼓励下走向他们 → 结局过场 + “1 岁生日”

### 3.4 可交互物件清单（Demo 范围）
床铃、奶瓶、安抚奶嘴、泰迪熊、积木 ×6、球、狗狗（可摸 / 被舔）、遥控器、抽屉（可拉开）、碗和勺子、纸巾盒（抽纸彩蛋）。

### 3.5 家长 AI（简单状态机）
`闲逛 → 听到哭声 → 走过来 → 判断最低需求 → 执行动作（喂 / 抱 / 哄睡 / 收走危险物）→ 回到闲逛`
- 配简单表情和咿呀式语音（无需真实对话）

## 4. 视听风格
- **低多边形（low-poly）+ 柔和粉彩**，暖色光、轻微 bloom
- 婴儿视觉：边缘暗角 + 景深模糊，初期远处更模糊（随成长清晰）
- 手部模型：胖乎乎的低模双手，始终在画面下方
- 音效：环境音（钟表、鸟叫）、咿呀声、家具碰撞的软乎乎音效
- 参考图见 `docs/concept/`

## 5. 场景
一套两居小公寓（Demo 只做 3 个区域）：
1. 婴儿房（婴儿床、床铃、小夜灯）
2. 客厅（地毯、沙发、茶几、玩具箱、狗窝）
3. 厨房（高脚椅、餐桌）

## 6. 技术方案
| 模块 | 选型 |
|---|---|
| 构建 | Vite + TypeScript |
| 渲染 | three.js（WebGL2），后期可试 WebGPU |
| 物理 | Rapier（@dimforge/rapier3d-compat） |
| 控制 | PointerLockControls 改造为“婴儿相机”（低高度、头部摆动、转头限制） |
| 手部 | 双手骨骼动画 + IK 抓取（简化：吸附到物件抓点） |
| 交互 | Raycaster 准星检测 + 可交互物件描边（OutlinePass） |
| 后处理 | EffectComposer：Bloom、景深（BokehPass）、暗角 |
| 状态 | 轻量 ECS 或简单 Store（needs / milestones / abilities） |
| 资源 | Blender 低模导出 glTF；初期用基础几何体占位 |
| 音频 | three.js PositionalAudio |
| 部署 | GitHub Pages / Cloudflare Pages |

### 目录结构（规划）
```
src/
  core/        # 游戏循环、输入、事件总线
  player/      # 婴儿相机、双手、能力解锁
  systems/     # 需求、里程碑、家长 AI
  world/       # 场景加载、可交互物件
  ui/          # HUD、提示
  fx/          # 后处理
public/models  public/audio
docs/
```

## 8. 后续阶段预留
- 存档系统设计为“人生档案”：婴儿期的选择（更爱探索 / 更黏人）影响后续性格属性
- 能力系统可扩展：说话、走路、骑车、写字……
- 场景按“人生阶段”分包加载
